# 8080-5-CI
<img src="8080-5 CI_top.png">

Debug and download module. To connect to the debugging board - https://github.com/R2AKT/Stepper.

Allows you to read and write data from/to memory and I/O ports.

Модуль отладки и загрузки. Для подключения к плате отладки - https://github.com/R2AKT/Stepper.

Позволяет считывать и записывать данные из/в памяти, портов ввода-вывода.

Прошивка для Arduino Nano прилагается (тестовая версия).

ПО для PC под Windows и Linux в настоящее время разрабатывается (стадия тестирования).
