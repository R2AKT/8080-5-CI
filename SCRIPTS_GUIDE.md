## Введение

Скрипты автоматизации позволяют управлять программой с помощью Python-кода:

- ⚙️ **Автоматизация** — заполнение памяти паттернами, поиск, патчинг
- 🧪 **Тестирование** — запись/чтение памяти, тестирование IO-портов
- 🔄 **Сложные сценарии** — считывание прошивки, модификация, загрузка обратно
- 🔍 **Анализ кода** — дизассемблирование, поиск инструкций, подсчёт команд

## Архитектура API

API разделён на три категории:

```
┌─────────────────────────────────────────────────────────────┐
│                    ЛОКАЛЬНЫЕ МЕТОДЫ                         │
│  read_mem, write_mem, disassemble, search, load_file        │
│  Работают с локальным образом памяти                        │
│  НЕ требуют подключения к устройству                        │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                  МЕТОДЫ УСТРОЙСТВА                          │
│  dev_read_mem, dev_write_mem, dev_read_io, dev_write_io     │
│  Работают с реальным устройством через COM-порт             │
│  Требуют подключения и захвата шины                         │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                 МЕТОДЫ СИНХРОНИЗАЦИИ                        │
│  download, upload, download_all, upload_all                 │
│  Передают данные между устройством и локальным образом      │
│  Требуют подключения и захвата шины                         │
└─────────────────────────────────────────────────────────────┘
```

## Основы работы

1. Откройте вкладку **«Scripts»** (или **«Скрипты»**).
2. Введите код в редактор.
3. Нажмите **«▶ Run Script»**.
4. Результаты появятся в области **Output**.

Используйте `print()` для вывода:

```python
print("Hello from script!")
print(f"Value: {0x55:02X}")
```

## Справочник API

### Управление шиной

| Метод | Описание | Возвращает |
|---|---|---|
| `hold_bus()` | Отправить команду захвата шины | `True` если отправлена |
| `unhold_bus()` | Отправить команду освобождения шины | `True` если отправлена |
| `wait_bus(timeout=5.0)` | Ждать захвата шины | `True` если захвачена |
| `wait_unhold(timeout=5.0)` | Ждать освобождения шины | `True` если освобождена |

```python
hold_bus()
if wait_bus():
    print("Bus is active!")
    # ... работаем с устройством ...
    unhold_bus()
    wait_unhold()
```

### Локальная память

> 💡 Не требует подключения к устройству.

| Метод | Описание |
|---|---|
| `read_mem(addr)` | Прочитать байт из локального образа |
| `write_mem(addr, val)` | Записать байт в локальный образ |
| `read_block(addr, size)` | Прочитать блок из локального образа |
| `write_block(addr, data)` | Записать блок в локальный образ |
| `fill_mem(addr, size, val)` | Заполнить диапазон значением |

### Память устройства

> ⚠️ Требует подключения **и** захвата шины.

| Метод | Описание |
|---|---|
| `dev_read_mem(addr)` | Прочитать байт из памяти устройства |
| `dev_write_mem(addr, val)` | Записать байт в память устройства |
| `dev_read_io(port)` | Прочитать из IO-порта устройства |
| `dev_write_io(port, val)` | Записать в IO-порт устройства |

### Синхронизация

> ⚠️ Требует подключения **и** захвата шины.

| Метод | Описание |
|---|---|
| `download(addr, size)` | Считать блок из устройства в локальный образ |
| `upload(addr, size)` | Записать блок из локального образа в устройство |
| `download_all(start, end)` | Считать всю память устройства |
| `upload_all()` | Записать весь локальный образ в устройство |

### Дизассемблирование и поиск

| Метод | Описание |
|---|---|
| `disassemble(addr, length, show=False)` | Дизассемблировать локальный образ. `show=True` обновляет окно дизассемблера |
| `search(pattern, mode)` | Поиск. `mode`: `"hex"` или `"ascii"` |

### Файлы и утилиты

| Метод | Описание |
|---|---|
| `load_file(path, base_addr=0)` | Загрузить файл в локальный образ |
| `save_file(path)` | Сохранить локальный образ в файл |
| `status()` | Состояние программы (словарь) |
| `log(msg)` | Вывод в журнал программы |
| `goto(addr)` | Переход к адресу в hex-редакторе |
| `refresh()` | Принудительное обновление GUI |

## Примеры скриптов

### Пример 1: Создание тестовой программы

```python
program = [
    0x3E, 0x55,       # MVI A, 55h
    0xD3, 0x01,       # OUT 01h
    0x3E, 0xAA,       # MVI A, AAh
    0xD3, 0x01,       # OUT 01h
    0xC3, 0x00, 0x00  # JMP 0000h
]

write_block(0x0000, program)
print("Test program written to 0x0000")

lines = disassemble(0x0000, len(program), show=True)
for line in lines:
    print(line)
```

### Пример 2: Поиск и анализ инструкций

```python
jmps = search('C3', 'hex')
print(f"Found {len(jmps)} JMP instructions:")

for addr in jmps:
    low = read_mem(addr + 1)
    high = read_mem(addr + 2)
    target = low | (high << 8)
    print(f"  0x{addr:04X}: JMP 0x{target:04X}")
```

### Пример 3: Полный цикл работы с устройством

```python
info = status()
if not info['connected']:
    print("ERROR: Device not connected!")
else:
    hold_bus()
    if wait_bus():
        data = download(0x0000, 256)
        print(f"Downloaded {len(data)} bytes")
        unhold_bus()
        wait_unhold()

        # Обработка локально
        nops = search('00', 'hex')
        for addr in nops[:10]:
            write_mem(addr, 0x3E)
            write_mem(addr + 1, 0x55)

        disassemble(0x0000, 256, show=True)

        hold_bus()
        if wait_bus():
            upload(0x0000, 256)
            unhold_bus()
            wait_unhold()
```

### Пример 4: Тестирование IO-портов

```python
hold_bus()
if wait_bus():
    for val in [0x00, 0xFF, 0x55, 0xAA]:
        dev_write_io(0x01, val)
        print(f"IO 0x01 = 0x{val:02X}")

    result = dev_read_io(0x02)
    if result is not None:
        print(f"IO 0x02 = 0x{result:02X}")

    unhold_bus()
    wait_unhold()
```

### Пример 5: Патчинг прошивки

```python
load_file("firmware.hex")

# Ищем все JMP на адрес 0x0000
results = search('C3 00 00', 'hex')
for addr in results:
    write_mem(addr, 0x00)
    write_mem(addr + 1, 0x00)
    write_mem(addr + 2, 0x00)

save_file("firmware_patched.hex")
print("Patched firmware saved")
```

## Лучшие практики

### ✅ Всегда проверяйте подключение и шину

```python
# ❌ ПЛОХО:
dev_write_io(0x01, 0x55)  # Может вызвать ошибку!

# ✅ ХОРОШО:
if status()['connected']:
    hold_bus()
    if wait_bus():
        dev_write_io(0x01, 0x55)
        unhold_bus()
        wait_unhold()
```

### ✅ Не обновляйте GUI в циклах

```python
# ❌ ПЛОХО: постоянное обновление GUI тормозит
for i in range(1000):
    write_mem(i, 0x00)

# ✅ ХОРОШО: обновляем один раз в конце
for i in range(1000):
    write_mem(i, 0x00)
refresh()
```

### ✅ Разделяйте анализ и отображение

```python
# Анализ без GUI (быстро)
lines = disassemble(0x0000, 1024)
jmp_count = sum(1 for line in lines if "JMP" in line)

# Отображение в GUI (один раз)
disassemble(0x0000, 1024, show=True)
```

### ✅ Обрабатывайте ошибки

```python
try:
    hold_bus()
    wait_bus()
    dev_write_io(0x01, 0x55)
except RuntimeError as e:
    print(f"ERROR: {e}")
finally:
    unhold_bus()
    wait_unhold()
```

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl+O` | Открыть файл прошивки |
| `Ctrl+S` | Сохранить дамп |
| `Ctrl+F` | Поиск по памяти |
| `Ctrl+G` | Переход к адресу |
| `Ctrl+E` | Экспорт дизассемблера |
| `Ctrl+D` | Дизассемблировать |
| `Ctrl+H` | Захват шины (HOLD) |
| `Ctrl+U` | Освобождение шины (UNHOLD) |
| `Ctrl+Z` / `Ctrl+Y` | Отмена / Повтор |
| `F5` | Обновить |
