{\bfseries{i8080-\/5 CI}} — среда разработки и отладки для процессора Intel 8080\+:


\begin{DoxyItemize}
\item Эмулятор i8080 (полный набор инструкций, флаги, стек, такты)
\item Отладчик\+: breakpoints, условные breakpoints, Run to Cursor, трассировка
\item Hex-\/редактор, дизассемблер со стрелками переходов
\item Работа с реальным устройством по SLIP-\/протоколу (COM-\/порт)
\item Встроенный MCP-\/сервер для AI-\/ассистентов
\end{DoxyItemize}

MCP-\/сервер запускается {\bfseries{внутри программы}} (вкладка «Управление», кнопка «\+MCP Server\+: ON») и доступен по SSE.
