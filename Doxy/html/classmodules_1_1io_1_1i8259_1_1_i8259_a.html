Detailed Description

8259A (КР1810ВН59) — контроллер прерываний С ICW4.

Добавляет:
- ICW4 (режим 8080/8086, Auto-EOI, Fully Nested Mode)
- Special Mask Mode (через OCW3)
Последовательность: ICW1 → ICW2 → ICW3 → ICW4 (если IC4=1) → READY.
